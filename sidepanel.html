❔ Hướng dẫn sử dụng

Extension giúp đọc/dịch tài liệu và học tiếng Anh. Trước tiên vào ⚙️ nhập OpenAI API Key — hầu hết tính năng AI cần nó.

🚀 Bắt đầu nhanh
  1. Bấm ⚙️ → dán API Key, chọn Model → Lưu.
  2. Bấm biểu tượng extension để mở side panel (hoặc phím Ctrl/⌘ + Shift + Y).
  3. Mở PDF (📄), dịch trang web (🌐) hoặc dán văn bản (📋) để bắt đầu.
📖 Dịch tài liệu
  • 📄 Mở PDF / 🌐 Dịch web (đang xem PDF trên web cũng bấm nút này) / 📋 Văn bản.
  • Bấm Dịch toàn bộ hoặc dịch từng đoạn; nút ↻ để dịch lại một đoạn.
  • Chế độ xem: Song ngữ / Tiếng Việt / Gốc. Bôi đen chữ để Dịch nhanh hoặc ＋ Từ vựng.
  • Bản dịch được cache 3 tuần nên mở lại không tốn phí. Đặt Bảng thuật ngữ trong ⚙️ để dịch nhất quán.
💬 Hỏi đáp
  • Tài liệu: hỏi về nội dung đang mở. Kho: RAG trên nhiều tài liệu đã nạp (📚). Tự do: chat như ChatGPT.
  • Nút 💬 trên mỗi đoạn để hỏi nhanh về đoạn đó. 🗑 xoá lịch sử.
🔤 Từ vựng & học IELTS
  • Tra cứu một từ (phiên âm, audio, nghĩa). Bôi đen khi đọc để lưu tự động.
  • ＋ Nạp từ IELTS: AI tạo bộ từ theo chủ đề (tự bỏ từ trùng). 📝 Kiểm tra: quiz có chấm điểm.
  • 🎯 Đề hôm nay: đề Writing/Speaking + chấm bài AI. 📊 Thống kê: mức nhớ, chuỗi ngày, sổ lỗi, lộ trình học.
  • Ôn theo lặp lại ngắt quãng (SM-2): chọn Quên/Khó/Được/Dễ; sai thì tự quay lại sớm.
📐 Ngữ pháp & 🗒️ Sổ tay
  • Ngữ pháp: tra cứu ngữ pháp + quy tắc/chiến lược IELTS (cố định, không cần mạng).
  • Sổ tay: ghi chú nhanh · Nhật ký (lịch tháng, có AI sửa tiếng Anh) · Việc cần làm.
🔒 Học thụ động (tùy chọn — mặc định TẮT)

Bật trong ⚙️ để trình duyệt chặn trang bắt học trước khi lướt:

  • Việc cần làm → Học từ vựng/ngữ pháp → Nhật ký (tối, có bù ngày thiếu).
  • Mạng xã hội: trả bài IELTS mỗi lần vào (giới hạn số lần/ngày).
  • Chế độ nhớ lại: bắt gõ đáp án thay vì chọn — nhớ lâu hơn.
⌨️ Phím tắt & mẹo
  • Ctrl/⌘ + Shift + Y: mở side panel. Ctrl/⌘ + Shift + D: dịch đoạn đang bôi đen.
  • Đổi phím tại brave://extensions/shortcuts.
  • Dữ liệu lưu cục bộ trong trình duyệt; API key chỉ gửi tới endpoint bạn cấu hình.
